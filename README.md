# Current Street Website


## Setup

Install dependencies with:

`npm install`

Run the development server:

`npm run dev`

Run the development server with access from other devices in the network with:

`npm run dev -- --host`

## How to keep packages up to date

- `npm outdated`: shows outdated packages
- `npm update`: updates packages
- `npm audit`: check for vulnerabilities
- `npm install <package>@latest`: install latest minor version of something
- for major updates use `npm install -g npm-check-updates` -> `ncu -u` -> 'npm install`
